# 协议字段

样本版本为 Android `1.35.20.001`、Unity `2022.3.62f3`、IL2CPP metadata v31。

## 传输头

| 位置 | 含义 |
| --- | --- |
| byte 0 | 头校验，`(len + flag + seq_lo + seq_hi) & 0xFF` |
| byte 1 | 低 4 位为 kind，4 和 5 表示数据。bit 4 为控制或 ACK，bit 5 为后续片，bit 6 表示还有后续片，bit 7 表示 Zstd |
| byte 2–3 | 小端序号 |

公共头为 8 字节，首段另外有 2 字节。分片首段置 `0x40`，后续片置 `0x20`，序号必须连续。整条消息重组后按标志位解压。同一个 UDP 包里的多条消息按头校验和连续序号拆开。

## 应用消息

消息前 4 字节依次为大端 `module` 和 `command`，各占 2 字节，后面是载荷。

| 消息 | 字段 |
| --- | --- |
| 3/852 场景帧 | 4、5 为帧号，6 为实体，7 为移除的实体 ID（varint 或 packed） |
| 实体 | 1 为运行时实体号，2 为次编号或预制体相关编号，3 为类别，4 为动作列表 |
| 动作 | 1 为动作类型，2 为 scale，3 为值（varint 或 packed），4 保留 |
| 3/1 登录 | 重置状态。2 为本地 UID，3 为本地实体号，5 为名单 |
| 3/3、3/6 | 更新名单。3/6 的字段 2 可以用 packed 或 unpacked UInt32 指定移除的 ID |
| 玩家 | 1 为 UInt32 实体号，2 为 UInt64 UID，3 为 UTF-8 姓名 |
| 3/2005 | 当前观察目标 |
| 855、861、858 | 依次为阶段变化、UInt32 到 UInt32 字典更新、UGC 语音录制 |

动作 1 的值是三个有符号 Int64 分量，按补码还原后除以 scale，样本里的 scale 为 1000。动作 31 的第一值经 `conv.i4` 得到 HP 原值。
