# release-r1：发布工具与文档修复

2026-11-23。运行版本仍为 v2.2-names-candidate，九个 src/dist 文件不变；本修订不是新游戏功能版本。

## 自审问题的处理

1. ZIP 改用 Python 标准 zipfile 生成 UTF-8 文件名；最终需直接按四个中文脚本路径验证，无需手动转码。
2. 部署器裸 --write 拒绝；电脑使用 --stage，本地手机挂载使用 --android-local。所有模式明确 transferred=false、started=false，手动传输步骤已补。
3. 发布检查补充私有/生成目录、危险扩展名、未知类型、非 UTF-8/二进制文本、缺失文件安全处理、发布清单、原运行哈希与可选 ZIP 检查。不会自动刷新清单，不审查 Git 历史，不提供全面隐私保证。
4. tools/research 的 Path 文本读写显式 UTF-8；控制台结构化报告使用 ASCII 转义降低电脑终端编码风险。原运行文件不动。
5. 撤下无同口径来源的双向应用总数；列出可追溯的入站 2830 口径，收紧固定哈希门禁与额外 HP 字段语义表述。
6. 三个 .NET 8 工程明确为电脑端 SDK 构建待验收，不安装 SDK 或冒称通过。依赖安装可能联网与后续离线分析分开。
7. 重放保护所有输入和已存在输出，禁止 summary/events 冲突；先检查经典 PCAP 结构，区分错误、无事件、部分处理。0 仍不是全恢复保证。
8. Python/libzstd 与 Android 原生命令分层检查；check_android.sh 需用户手动在原生 Root shell 运行，不自动提权/启动任何采集；--android 静态输出不再冒称设备就绪。

## 验收纪律

本修订仅做直接相关的语法、文件一致性和辅助工具最小检查，不重复已通过的全量游戏回归，不生成游戏模拟场景。不启动游戏、抓包、服务或真实设备部署。

最终 ZIP 哈希、实际检查结果与仍待电脑/手机实测的事项保存在包外修复记录；未取得成功输出的事项不写为通过。MIT 方案与署名、远程仓库和公开发布仍需用户决定与明确授权。
