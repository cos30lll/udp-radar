# 已知限制

- 解析器按固定版本的协议实现，其他版本的传输头、字段和 token 可能变化。[协议字段](PROTOCOL.md)
- 输入是经典 PCAP。IPv4 和 IPv6 的 IP 分片会跳过，传输分片缺段或乱序时会丢弃。同一 UDP 包的拆法不唯一时记为解码错误。压缩消息使用带输出上限的 Zstd。
- 抓包需要 Android Root、`tcpdump`、`ss` 和 proot Ubuntu。辅助进程或短暂出现的端口可能漏掉。升级后要重启会话，运行中的 Python 进程会继续使用原先载入的代码。
- 页面能显示的是游戏发到本机的数据。姓名没随名单到达时，实体列表显示“未收到”。观战时标记的自己可能是观察目标。HP 显示原值，额外字段 `values[4]` 的含义待确认。
- 页面用坐标和轨迹绘图。底图与配准、朝向补偿、预测插值、敌我判断和血量百分比超出当前功能范围。
- 设备上的 PCAP 可能包含玩家数据和其他应用的流量。分享时用脱敏统计或合成样本。[隐私说明](PRIVACY.md)
